# CS 330: Computational Graphics and Visualization – Portfolio Submission

## Reflection

### How do I approach designing software?
When designing software, I start by identifying the project goals and any limitations. I then break the problem into smaller components and create a plan that outlines how each part will interact. For this project, I especially focused on planning the relationships between 3D objects, camera movement, and user interaction before coding.

### What new design skills did this project help me develop?
Working on this project enhanced my ability to design 3D environments with attention to spatial awareness and user experience. I also learned how to implement features like lighting, object transformation, and camera control to create a more immersive scene.

### What design process did I follow?
I used an iterative design process. I began by building the basic structure of the scene and gradually added complexity—like lighting, textures, and motion. I frequently reviewed my design document to stay aligned with the project goals and made adjustments based on testing and visual feedback.

### How could my design approach be useful in future work?
The modular and iterative approach I used can be applied to any future software project. Breaking complex problems into manageable parts and refining each one over time will help in areas like game development, simulations, and interactive UI design.

### How do I approach developing programs?
I typically begin by building a simple prototype and then incrementally add new features. I focus on clean, well-organized code and use version control to track my progress. This project reinforced the importance of testing each new element as I added it.

### What new development strategies did I use while working on the 3D scene?
I practiced using transformation matrices, implemented basic frame-by-frame animation, and improved my understanding of real-time rendering with OpenGL. I also gained experience loading textures and managing multiple objects in a scene.

### How did iteration factor into the development process?
Iteration was a key part of development. Each milestone built upon the last, allowing me to refine existing features while adding new ones. I often revisited earlier code to improve performance and visual consistency based on what I learned later in the project.

### How has my development approach evolved through the milestones?
Early in the project, my focus was mainly on functionality. As the project progressed, I started emphasizing efficiency, reusability, and visual design. By the end, my approach included more planning and testing to ensure a polished final product.

### How can computer science help me reach my goals?
Computer science gives me the tools and mindset to solve complex problems and create meaningful solutions. Whether I pursue software development, UI/UX, or simulations, the skills I’ve learned will support my professional and academic growth.

### How do computational graphics and visualizations support my educational goals?
This project gave me practical experience with concepts like vector math, 3D transformations, and rendering techniques. These topics will be valuable as I explore advanced courses in game design, simulation, or virtual reality.

### How do computational graphics and visualizations support my professional goals?
Understanding 3D graphics and visualization opens opportunities in fields like game development, interactive media, and data visualization. These skills help me design engaging, user-centered experiences and better communicate complex information through visual means.
